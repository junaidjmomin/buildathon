--- S2.3 GENUINE DEFECT: narration tokenizer destroyed identifiers -----------
The inherited fix split narration tokens on BOTH "/" and "_". Since "_" occurs
*inside* identifiers, "RZP/SET_TOKEN_1/SETTLEMENT" tokenized to
{rzp,set,token,1,settlement} and the settlement id was never a token, so a
VERBATIM reference was not recognised as exact identification — it only
squeaked past the threshold as FUZZY. Proven by a new regression test.
FIX (app/ingestion/pipeline.py): two-level tokenization with distinct
purposes. _narration_tokens() splits on structural delimiters only
("/\|,;:()[]{}<>-" + whitespace) leaving "_"-joined identifiers whole -> used
for the exact-identification decision. _tokens() sub-splits those on "_" ->
used only for the graded fuzzy overlap signal. Result: verbatim embedded
references match as EXACT with token overlap 1.0000.
